# Bestiario de Minecraft ⛏️

Explorador de mobs de Minecraft hecho con React, TypeScript, React Router, Zustand y Tailwind CSS. Es el Proyecto 01 de Desarrollo Front-End.

Los datos vienen de [Minecraft API](https://minecraft-api-dusky.vercel.app/documentation). Es un proyecto universitario sin relación oficial con Mojang ni Microsoft.

## Correr el proyecto

```bash
pnpm install
pnpm dev
```
